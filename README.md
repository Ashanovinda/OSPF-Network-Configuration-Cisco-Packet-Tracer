# OSPF Network Configuration 

This project demonstrates a fully functional OSPF (Open Shortest Path First) routing protocol configuration built using **Cisco Packet Tracer**.

##  Project Overview
In this lab, I have designed and configured a network topology to establish communication between different network segments using the OSPF dynamic routing protocol.

##  Tools & Technologies Used
* **Simulator:** Cisco Packet Tracer
* **Protocol:** OSPF (Open Shortest Path First)
* **Devices Used:** Cisco Routers, Switches, and PCs

##  Network Topology Highlights
* Configured IP addressing for multiple subnets (e.g., 192.168.10.0/24, 192.168.20.0/24).
* Established OSPF neighbor relationships.
* Verified connectivity using `ping` and `show ip route` commands.


##  How to Run
1. Download the `.pkt` file from this repository.
2. Open it using Cisco Packet Tracer.
3. Check the router configurations using CLI commands like `show ip ospf neighbor`.
